# Kalkulator BK2% – nadpłacać czy inwestować w obligacje?

Jednoplikowa aplikacja dla osób z Bezpiecznym Kredytem 2%: ile kredytu spłacisz w dniu zakończenia dopłat, odkładając co miesiąc w obligacje skarbowe, i ile trzeba odkładać, żeby spłacić całość.

- `index.html` – cała aplikacja (HTML + CSS + JS, bez zależności). Otwórz dwuklikiem, działa offline.
- `tests.mjs` – testy silnika obliczeń: `node tests.mjs`.
- `SPEC.md` – specyfikacja.

To symulacja, nie porada finansowa.
